# Getting Started with WhatsApp

WhatsApp is a free messaging app that works on mobile and desktop.  
To begin, you’ll need a smartphone number to register.  

- Download WhatsApp from your device’s app store or the official website.  
  - Verify your phone number with the OTP sent via SMS.  
    - Set up your profile with a name and optional photo.  
    - Start chatting with your contacts instantly.
