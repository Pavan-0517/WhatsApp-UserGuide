# WhatsApp Best Practices Checklist

## Privacy

- [ ] Enable **Two-Step Verification** for added account security.
- [ ] Review and adjust **Last Seen, Profile Photo, and Status** visibility.
- [ ] Block or report suspicious contacts.
- [ ] Avoid sharing sensitive personal information in chats.

## Backups

- [ ] Set up **automatic backups** (Google Drive for Android, iCloud for iOS).
- [ ] Verify backup frequency (daily/weekly).
- [ ] Ensure enough cloud storage space.
- [ ] Test restoring chats from backup periodically.

## Security

- [ ] Keep WhatsApp updated to the latest version.
- [ ] Verify app permissions (camera, microphone, storage).
- [ ] Use strong device lock (PIN, fingerprint, Face ID).
- [ ] Regularly review linked devices and remove unused ones.

## Usage

- [ ] Limit group membership to trusted contacts.
- [ ] Avoid forwarding spam or chain messages.
- [ ] Respect media size limits (16 MB for videos/images, 100 MB for documents).
- [ ] Use **Status** responsibly — remember it disappears after 24 hours.
